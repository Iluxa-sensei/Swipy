# SQL Scripts Execution Order

## 📋 **Правильный порядок выполнения SQL скриптов в Supabase SQL Editor:**

### **1. Основная схема**
```sql
-- Выполните: supabase/schema.sql
-- Создает основную структуру базы данных
```

### **2. Расширение профилей**
```sql
-- Выполните: ENHANCE_PROFILE_SCHEMA.sql
-- Добавляет таблицы для портфолио, достижений, опыта работы и образования
```

### **3. Полная настройка системы профилей**
```sql
-- Выполните: COMPLETE_PROFILE_UPGRADE.sql
-- Создает sample данные и функции для работы с профилями
```

### **4. Оптимизация базы данных**
```sql
-- Выполните: OPTIMIZE_DATABASE.sql
-- Оптимизирует производительность и добавляет недостающие колонки
```

### **5. Исправление проблем линтера**
```sql
-- Выполните: FIX_DATABASE_LINTER_ISSUES.sql
-- Исправляет проблемы производительности и безопасности
```

### **6. Синхронизация данных onboarding**
```sql
-- Выполните: SYNC_ONBOARDING_DATA.sql
-- Синхронизирует данные из onboarding с системой профилей
```

### **7. Чат система**
```sql
-- Выполните: FIX_CHAT_SYSTEM.sql
-- Настраивает startup-specific чат систему
```

### **8. Исправление проблем с удалением**
```sql
-- Выполните: FIX_DELETE_ISSUES.sql
-- Исправляет ошибки удаления стартапов и удаляет шаблонные данные (безопасная версия)
```

## ⚠️ **Важные замечания:**

1. **Выполняйте скрипты строго в указанном порядке**
2. **Каждый скрипт должен завершиться успешно перед переходом к следующему**
3. **При ошибках проверяйте, что предыдущие скрипты выполнены полностью**
4. **После выполнения всех скриптов перезапустите приложение**

## 🎯 **Результат:**

После выполнения всех скриптов у вас будет:
- ✅ Современная система профилей с портфолио
- ✅ Startup-specific чат система
- ✅ Оптимизированная база данных
- ✅ Исправленные проблемы производительности
- ✅ Безопасные RLS политики

## 🔧 **Проверка:**

После выполнения всех скриптов:
1. Проверьте, что приложение запускается без ошибок
2. Убедитесь, что профили отображаются корректно
3. Проверьте работу чат системы
4. Убедитесь, что создание стартапов работает
5. Проверьте, что удаление стартапов работает без ошибок
